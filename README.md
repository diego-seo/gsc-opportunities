# gsc-opportunities

Skill de Claude creado por [Diego González](https://github.com/diego-seo) · Diego Seo Web.

Detecta oportunidades de mejora SEO en datos de Google Search Console usando la matriz de 4 cuadrantes (Posición × CTR).

## Instalación

1. Descarga este repositorio como ZIP (botón **Code → Download ZIP**).
2. En Claude, ve a **Settings → Capabilities → Skills** y sube el ZIP.
3. El skill se activa solo cuando la conversación coincide con su descripción en `SKILL.md`.
